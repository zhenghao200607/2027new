## 一、环境信息

| 项目 | 值 |
|---|---|
| 虚拟机软件 | Oracle VirtualBox 7.2.16 |
| 操作系统 | **Ubuntu 24.04 LTS (Noble Numbat)** 64-bit |
| ROS 2 版本 | **Jazzy**（`echo $ROS_DISTRO` 输出 `jazzy`） |
| 安装方式 | 鱼香 ROS 一键安装脚本（http://fishros.com/install） |
| 机器配置 | 4 GB 内存 / 8 vCPU / 80 GB 虚拟硬盘 |

> 考核题要求 Ubuntu 24.04 + ROS 2 Jazzy，本环境完全符合。

### 环境变量的自动加载情况（实测）

- **ROS 2 自身**：一键脚本已经把 `source /opt/ros/jazzy/setup.bash` 写进了 `~/.bashrc`，
  所以**新开的终端**里 `echo $ROS_DISTRO` 会直接输出 `jazzy`，不用手动 source。
- **自己构建的工作空间**：`~/nav_ws/install/setup.bash` 需要**手动 source**
  （或者也写进 `.bashrc`）—— 考核题要求掌握的就是这一步。

## 二、操作步骤

### 1. 建工作空间

```bash
mkdir -p ~/nav_ws/src
cd ~/nav_ws
```

ROS 2 的工作空间结构是固定的：

- `src/` —— 放所有功能包的源码（**手动创建**）
- `build/`、`install/`、`log/` —— 构建时**自动生成**

### 2. 放入功能包

把 `src.zip` 解压后得到的包放进工作空间的 `src/` 下：

```bash
unzip src.zip
cp -r ~/src ~/nav_ws/src/daohang
```

放好后的结构：

```
~/nav_ws/src/daohang/
├── CMakeLists.txt
├── package.xml
├── include/daohang/
└── src/daohang.cpp
```

### 3. 构建（考核题要求的第一条命令）

```bash
cd ~/nav_ws
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
```

**构建结果：**

```
Starting >>> daohang
Finished <<< daohang [1.83s]

Summary: 1 package finished [2.08s]
```

截图见 `01-colcon-build成功.png`。

**参数说明：**

| 参数 | 作用 |
|---|---|
| `colcon build` | ROS 2 的构建命令，会扫描 `src/` 下的每个包按依赖顺序构建 |
| `--symlink-install` | 安装时用符号链接而非复制文件，改 Python/launch/yaml 后无需重新构建 |
| `--cmake-args` | 后面的参数原样传给 CMake |
| `-DCMAKE_BUILD_TYPE=Release` | 构建类型设为 Release（开 `-O3` 优化、不含调试信息），适合部署与测试 |

### 4. 配置环境变量（考核题要求的两种方式）

ROS 2 靠**环境变量**（主要是 `AMENT_PREFIX_PATH`）定位功能包，所以构建完必须 source。

**方式一：写进 `~/.bashrc`（一劳永逸）**

```bash
gedit ~/.bashrc
# 在最后一行加上：
source ~/nav_ws/install/setup.bash

# 然后让改动立即生效
source ~/.bashrc
```

**方式二：每次手动 source**

```bash
cd ~/nav_ws
source ./install/setup.bash
```

**注意区别**：`.bashrc` 是 bash 每次启动时自动执行的配置脚本；
`source` 的作用是**在当前 shell 里**执行脚本（而不是开一个子 shell），所以环境变量才能留在当前会话。

### 5. 运行（考核题要求的第二条命令）

```bash
source install/setup.bash
ros2 run daohang daohang.cpp
```

**运行结果**：程序每 0.5 秒输出一行

```
这里是2027导航考核第二题awa
这里是2027导航考核第二题awa
...
```

截图见 `02-ros2-run输出.png`。

> ⚠️ **注意可执行文件名**：`CMakeLists.txt` 里写的是
> `add_executable(daohang.cpp src/daohang.cpp)`，目标名带 `.cpp`，
> 所以运行命令必须是 `ros2 run daohang daohang.cpp`，
> 写成 `ros2 run daohang daohang` 会报找不到可执行文件。

## 三、踩坑记录

### 坑 1：`colcon build` 报 `unrecognized arguments: --symlink-install`

**现象**：同一条命令，第一次报错，切成英文输入法后重敲一次就成功了。

**原因**：虚拟机里开着中文输入法，`-` 被打成了全角 `－`。
`--symlink-install` 变成 `－－ｓｙｍｌｉｎｋ－ｉｎｓｔａｌｌ`，
看着几乎一样，但 colcon 解析不了。

**解决**：敲命令前先按 `Shift` / `Ctrl+空格` 把输入法切到**英文模式**。

**教训**：在 Linux 终端里敲命令，**必须用英文半角输入**。
全角字符肉眼很难分辨，报错信息也不会明说是这个原因。

### 坑 2：`找不到命令 "ros"`

**现象**：执行 `ros2 run daohang daohang.cpp` 时，报

```
找不到命令 "ros"，您的意思是：
 "rs" 命令来自 Debian 软件包 rs ...
```

注意报错里说的是 `ros` 而不是 `ros2`。

**原因**：同样是输入法问题——`2` 被打成了全角 `２`，
bash 读到的命令名不是 `ros2`。

**解决**：切英文输入法后重新输入。

### 坑 3：运行正常，但弹出「应用程序 ros2 意外停止」崩溃报告

**现象**：`ros2 run daohang daohang.cpp` 执行后，终端**持续正常输出**预期内容，
但桌面上弹出了 Ubuntu 的崩溃报告对话框，提示 `ros2` 意外停止。

**排查**：
1. 先观察终端输出——一直在正常刷，说明 `daohang` 可执行文件运行正常
2. 判断崩溃的是 `ros2` 这个命令行外壳进程（一个 Python 程序），
   而不是我们构建出来的程序
3. 查看 `ros2 pkg executables daohang` 确认包和可执行文件都注册正常

**结论**：崩溃的是 `ros2` CLI 外壳，**不影响本考核题的验收**
（题目要求的是"在 Ubuntu 系统中将其运行"，程序本身运行完全正常）。
