## 考核一 · C++ 三题

代码在 `exam1/` 里。

### 第 1 题 · 10 个数升序输出（exam1_1.cpp）

用数组把 10 个数存起来，再用冒泡排序输出。内层循环我写的是 `j < N - i - 1` 而不是 `j < N - 1`，因为每跑完一轮末尾就多一个已经就位的数，N=10 时比较次数从 81 次降到 45 次。

踩的坑：读入那行我把 `a[i]` 写成了 `std::cin >> a[N];`。N 是 10，合法下标只到 9，所以这是越界。编译器没有报错，程序也能跑，但排序结果不对。

【✍️ 郑浩自己写：接在上面这段后面，写你当时的想法和后来搞明白的东西。提示——你原来以为越界编译器会拦下来，结果编译时一句话都没说，程序还正常跑完（exit code 0）。后来才知道编译器其实能查，只是要开优化：`-O0` 没有任何警告，同一份代码换成 `-O2` 就报出 3 条 `-Warray-bounds`。还可以提越界属于未定义行为，你实测过同一个 exe 连跑四次，读出来的值每次都不一样。写 4~6 句。】

### 第 2 题 · 结构体与指针（exam1_2.cpp）

定义 `struct Student`，写 `input()` 和 `display()` 两个函数，通过指针接收结构体、用 `->` 取成员，在 `main()` 里用 `new` 动态创建一个。

一开始我完全分不清"指针"和"对象"。后来想明白了：`s` 是对象，像一个盒子，`s.name` 直接拿；`p` 是指针，是一张写着地址的纸条，纸条上没有 `name` 这个格子，必须顺着纸条找到盒子，也就是 `p->name`。`p->name` 完全等价于 `(*p).name`，如果对指针用 `.`，编译器会直接报错。

为什么要传指针：C++ 默认按值传递，会把实参复制一份给函数，函数改的是副本，所以必须把地址传进去才能改到原来的对象。我写了个演示程序对比地址验证过这件事。

`new` 在堆上分配内存并调用构造函数，`delete` 会先调用析构函数再把内存还给系统，两个必须配对。

踩的坑：箭头位置写反过（`->pscore`）、函数名 `display` 拼成了 `displey`、输出的中文冒号漏掉过 —— 都是编译器报错或者对照题目才发现。

### 第 3 题 · Car 类（exam1_3.cpp）

定义 `class Car`，私有成员 `color` 和 `number`，公有的构造函数、析构函数、`display()`，在 `main()` 里创建两个对象。

第一次接触"类"，我的理解是把数据和操作这些数据的函数打包在一起。构造函数名字和类名相同、没有返回类型、创建对象时自动调用，不能手动调。析构函数名字是 `~` 加类名，对象销毁时自动调用，证明方法就是在里面打印一句话。

我的程序实际输出：

```
颜色：红色  车牌号：1001
颜色：蓝色  车牌号：1002
Car对象被销毁了，车牌号1002
Car对象被销毁了，车牌号1001
```

car2 是后创建的，却先被销毁。

【✍️ 郑浩自己写：解释为什么是这个顺序。提示——局部对象都在栈上，栈是后进先出（LIFO），所以析构顺序是构造顺序的逆序。再提一句销毁的时机是"离开作用域"（离它最近的那个 `}`），不是程序结束。最后可以说 `new` 出来的对象不一样：住在堆上，不写 `delete` 的话析构函数根本不会被调用，你实测过。写 4~6 句。】

`class` 和 `struct` 的唯一本质区别是默认访问权限：`class` 默认 private，`struct` 默认 public。成员设成 private 是为了封装，不然外面可以直接写 `car1.number = -999;`。

踩的坑：`class Car()` 多写了一对括号；`};` 放错位置让 `display()` 跑到类外面去了；字符串用了单引号，`std::cout << '  ';` 打出来是数字 8224，必须用双引号。

## 考核二 · ROS 2

环境是 VirtualBox 里装的 Ubuntu 24.04 LTS，ROS 2 Jazzy（用鱼香 ROS 的一键安装脚本装的）。

步骤：建工作空间 `~/nav_ws` → 把 `src.zip` 解压出的 `daohang` 包放进 `src/` → `colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release` → source 环境变量 → `ros2 run daohang daohang.cpp`

构建成功：

```
Starting >>> daohang
Finished <<< daohang [1.83s]

Summary: 1 package finished [2.08s]
```

截图在 `exam2/` 里，详细说明在 `exam2/说明.md`。

有两点我印象比较深：一是运行命令必须写 `ros2 run daohang daohang.cpp`，因为 `CMakeLists.txt` 里 `add_executable` 的目标名是带 `.cpp` 的；二是不 source 环境变量的话，系统不知道你刚构建了什么，会报 `Package 'daohang' not found`。

踩的坑：`colcon build` 报 `unrecognized arguments: --symlink-install`，这条命令教程里明明是对的，后来发现是中文输入法把 `-` 打成了全角 `－`；还有一次 `ros2 run` 报 `找不到命令 "ros"`，是 `2` 被打成了全角 `２`，屏幕上几乎看不出区别。另外有一次运行时终端输出一直正常，桌面上却弹出「应用程序 ros2 意外停止」，我判断崩的是 `ros2` 这个命令行外壳，不是我们构建的程序。

## 考核三 · GitHub

仓库地址：https://github.com/zhenghao200607/2027new

我的理解：`git add` 把改动的文件放进暂存区，`git commit` 把它记录成一次提交，`git push` 推送到远程仓库。分三步的好处是可以选择性提交 —— 改了 5 个文件但只想提交 3 个，就用 `git add` 挑出来。

踩的坑：第一次 push 报 `Password authentication is not supported for Git operations`，查了才知道 GitHub 现在禁止用账号密码做 git 操作，必须用 Personal Access Token。另外 push 经常报 `Connection was reset`，但因为 commit 已经存在本地仓库了，代码不会丢，重试就好。
